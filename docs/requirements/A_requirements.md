# A — 要件定義（機械可読アンカー版）: 顧客離脱予兆検知 兼 クロスセル推奨システム

> 元文書: 「要件定義書 3：顧客離脱予兆検知 兼 クロスセル推奨システム（ML-Churn-Recommend）」
> 本書は Claim Auditor が解釈できるよう各要件に機械可読アンカー（`FR-x` / `NFR-x`）を付番した A 文書。
> 受け入れ条件は [`B_acceptance.md`](B_acceptance.md) を参照。

## 1. 目的とビジネス価値
サブスク型／リピート型ビジネスの既存顧客の解約（チャーン）リスクを早期検知し、同時に LTV を
高める最適なクロスセル提案を自動生成するデモプロダクト。離脱防止による売上維持効果と、
データ根拠に基づく効率的なアプローチリストの自動生成による業務効率化を証明する。

## 2. 機能要件 (Functional Requirements)

### 2.1 離脱予兆検知パイプライン
- **FR-1** LightGBM もしくは XGBoost の二値分類で、顧客ごとの離脱確率（0.0〜100.0%）を算出する。
- **FR-2** 入力データとして顧客属性・ログイン頻度・機能利用ログ・過去の支払履歴・サポート問い合わせ回数を受け付ける。

### 2.2 問い合わせテキストの感情・類似性分析
- **FR-3** サポート問い合わせテキストをベクトル化（Sentence-Transformers もしくは埋め込み）し、「不満」「解約の匂わせ」を含む類似ケースを検知する。
- **FR-4** テキスト分析結果を離脱予測の補正特徴量として組み込む。

### 2.3 理由の可視化 (Explainable AI)
- **FR-5** SHAP により、顧客ごとに「なぜ離脱リスクが高いと判断したか」の要因を寄与度グラフとして可視化する。

### 2.4 クロスセル推奨パイプライン
- **FR-6** 協調フィルタリング（LightFM）もしくはグラフ解析（NetworkX）で、上位 3 製品・オプションを推奨する。
- **FR-7** 推奨対象は、離脱リスクが低くアクティブな顧客、または離脱要因をケアした顧客とし、過去の類似購買パターンから次に契約・購入する可能性が高い製品を提示する。

### 2.5 ダッシュボード表示
- **FR-8** 離脱リスク％の降順でソートした高リスク顧客アラートリストを表示する。
- **FR-9** Streamlit による CRM 連携型ダッシュボードで、アラートリスト・SHAP 可視化・クロスセル推奨を一画面で提示する。

## 3. 非機能要件 (Non-Functional Requirements)
- **NFR-1** 言語・スタックは Python 3.10+ / Streamlit とする。
- **NFR-2** Telco 風の合成顧客データ＋合成サポートテキスト（100 件程度）を同梱し、外部接続なしで即実行できる。
- **NFR-3** 離脱分類モデルの精度指標（AUC / Accuracy 等）を提示する。
